# 🌱 Terra Viva — Gestão e Rastreabilidade Agroecológica

## Sobre o projeto

O Terra Viva é uma solução digital desenvolvida para auxiliar
na organização e no acompanhamento das atividades de uma iniciativa
de produção agroecológica.

O projeto surgiu a partir de uma necessidade real de organizar
informações que anteriormente eram registradas de forma manual.

## 🎯 Problema

A produção agroecológica envolve diferentes tipos de informações,
como plantios, manejos, colheitas, produtos comercializados e vendas.

Quando esses registros ficam dispersos ou são realizados apenas
em papel, torna-se mais difícil consultar o histórico e manter
as informações organizadas.

## 💡 Solução

O sistema foi pensado para centralizar essas informações em uma
aplicação digital, facilitando o registro, a consulta e o
acompanhamento das atividades relacionadas à produção.

## 📋 Funcionalidades

- Cadastro e organização de informações da propriedade
- Registro de produtos
- Registro de manejos e plantios
- Registro de vendas
- Organização das informações de produção
- Relatórios e registros para acompanhamento
- Informações relacionadas à rastreabilidade

## 🌱 Contexto

O projeto foi desenvolvido considerando as necessidades do Grupo
Terra Viva, ligado à produção agroecológica no assentamento
Carlos Lamarca, em Itapetininga-SP.

A proposta é utilizar a tecnologia para facilitar a organização
dos registros e apoiar a rastreabilidade da produção.

## 🛠️ Tecnologias

- Banco de dados
